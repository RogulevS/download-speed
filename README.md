# Замер скорости скачивания

Консольный скрипт на Python. Берёт адрес, скачивает его **10 раз подряд**, каждый раз дожидается всего тела ответа и печатает среднее время запроса, общий объём и скорость.

Сторонние пакеты не нужны: только стандартная библиотека. Подойдёт Python 3.9 и новее.

## Единицы

| Что | Единица | Как считается |
| --- | --- | --- |
| Время запроса | секунды (с), три знака после запятой | от начала запроса до последнего байта тела |
| Среднее время | секунды (с) | среднее арифметическое десяти длительностей |
| Объём | байты и мебибайты (МиБ) | сумма тел ответов. 1 МиБ = 1024 × 1024 байт |
| Скорость | мегабиты в секунду (Мбит/с) и мебибайты в секунду (МиБ/с) | общий объём ÷ сумма времён запросов |

1 Мбит/с = 1&nbsp;000&nbsp;000 бит/с — так скорость обычно указывают провайдеры.
Рядом в скобках та же скорость в МиБ/с: байты ÷ секунды ÷ 1024².

В объём входит тело ответа, как оно пришло по сети. Сжатие не запрашивается (`Accept-Encoding: identity`), поэтому байты в отчёте — это скачанные байты, а не распакованный размер.

## Запуск

```bash
python3 speed.py "https://speed.cloudflare.com/__down?bytes=2000000"
```

Адрес со знаком `?` лучше брать в кавычки, иначе оболочка может его обрезать.

Свой файл, например тяжёлая картинка:

```bash
python3 speed.py "https://example.com/large-photo.jpg"
```

Лимит одного запроса по умолчанию 60 секунд. Для большого файла его можно поднять:

```bash
python3 speed.py --timeout 180 "https://example.com/large-photo.jpg"
```

Нужен абсолютный адрес со схемой `http://` или `https://`. Редиректы скрипт проходит. Если заданы `http_proxy` или `https_proxy`, запросы идут через них.

Код выхода: `0` — все 10 запросов дочитаны, `1` — запрос не удался или сервер вернул код 4xx/5xx, `2` — неверный аргумент.

Пока идёт замер, после каждого ответа печатается короткая строка. Итог — в конце.
